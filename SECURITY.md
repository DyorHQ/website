# Security

Please report security vulnerabilities in DyorHQ (the website, the iOS app, the web app, the backend or the smart
contracts) privately to **team@dyorhq.fun** with the subject "Security report". Include what is affected, how to
reproduce it and the impact. Do not open a public issue.
